## 091601 Phase 1 — Project runbooks

### Customize mode (project only)

- Toggle **Customize off / on** on Project → Runbooks tab (persisted in `localStorage`).
- **Customize off:** execute mode (checks, closed, export) — same as before.
- **Customize on:** full work panel editor (bulk append, sections, drag, tags, AI append, row edits). Edits the **shared** `runbooks[]` template (all assignees see checklist text changes). Per-project progress stays in `runbookProgress`.

### Organization-only destructive actions

- **Delete entire runbook** — type `DELETE` to confirm; org library only.
- **Build** (replace all from bulk), **Import JSON replace**, **Remove accomplished from template**, AI **Replace all** — org library only (server-enforced via `assertOrganizationLibraryDestructive`).

### Child runbook links

- New item type `link` with `linkedRunbookId`.
- **Link to runbook** in bulk toolbar (customize/builder contexts).
- Row **Open** navigates in-tab; **Back to previous runbook** via `fromRunbook` query param.

### Not in Phase 1

- Per-entity overlay layer (C) — future; rollback TBD.
