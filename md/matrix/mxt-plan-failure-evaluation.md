## A-Iteration Anchors

### Anchor — Synthesis rule (exact)

> **MXT no debe intentar demostrar que cada Plan tenía sentido. Debe intentar falsarlo contra Reality. Si Reality queda materialmente fuera de la geometría esperada —con 2–3 distancias Entry→Stop como banda inicial a investigar— aceptamos que el Plan estuvo equivocado. Después intentamos explicar por qué; si la evidencia no alcanza, `inconclusive` es la respuesta correcta. El error se preserva como aprendizaje, no se racionaliza.**

### Anchor — Layers may diverge (exact)

> **Tesis correcta + Plan incorrecto + buena disciplina + 0R.**

### Anchor — Failure ≠ chase permission (exact)

> **Plan equivocado ≠ debimos perseguir.**

### Anchor — Failure without cause (exact)

> **Podemos demostrar que el Plan estuvo equivocado sin saber por qué estuvo equivocado.**

## Principio

**Reality debe utilizarse para intentar falsar el Plan, no para justificar retrospectivamente por qué parecía razonable.**

Sin un criterio falsable, el análisis tiende a seguir encontrando razones por las que un Entry “tenía sentido”. Ese sesgo es el defecto que este documento corrige.

---

## Evaluación (criterio limpio)

### 1. Separar Thesis de Plan

Una tesis puede ser correcta mientras el Plan es incorrecto.

No permitir que una tesis correcta “salve” retrospectivamente un Plan malo.  
No permitir que un Plan malo convierta automáticamente la tesis en mala.

### 2. Usar la geometría original del Plan como referencia

La distancia `Entry → Stop` sirve como **escala** para evaluar qué tan lejos quedó la estructura real de la estructura prevista.

Esto **no modifica** Realized R ni Counterfactual R.

Ejemplo de escala (SHOP / PLAN-005 — referencia de aprendizaje, no ley):

| Referencia | Valor |
|---|---|
| Entry | 136 |
| Stop | 125 |
| Distancia de riesgo (Entry→Stop) | 11 |
| +1 equivalente geométrico | 147 |
| +2 | 158 |
| +3 | 169 |
| Target | 180 |

La pregunta pasa de “¿el Entry era defendible?” a:

> **¿Dónde apareció realmente la estructura relevante respecto de la geometría que nosotros habíamos planteado?**

### 3. Evaluar proximidad estructural, no solamente `entryReached`

Un no-fill cercano puede representar un Plan aproximadamente correcto.  
Un mercado que desarrolla la oportunidad **materialmente lejos** de la geometría prevista constituye evidencia de error del Plan.

### 4. Banda inicial de análisis: ~2–3 distancias Entry→Stop

Guideline provisional de investigación — **no** ley estadística de MXT.

- Dentro de esa región todavía puede existir aproximación razonable según estructura y contexto.
- Cuando la estructura efectiva se desarrolla **materialmente fuera** de ella, debe considerarse evidencia fuerte de **Plan failure**.
- La banda requiere población para calibrarse. Un caso (SHOP) genera la hipótesis; no la cierra.

### 5. Plan failure no implica pérdida económica

Un Plan puede ser claramente incorrecto y conservar:

- `Realized R = 0R`
- `Counterfactual R = 0R`

cuando nunca hubo entrada.

**No confundir `0R` con “Plan neutral”.**

### 6. Plan failure no implica que debimos perseguir el precio

`No chase` puede haber sido una buena decisión incluso cuando posteriormente comprobamos que el Plan estaba equivocado.

Que el precio haya subido después **no** demuestra que perseguir habría sido una buena decisión.

### 7. Después de identificar Plan failure, la causa es una pregunta separada

Por ahora basta conservar dos hipótesis simples:

1. **Playbook equivocado / no identificado**
2. **Market happens / inconclusive**

No es necesario decidir entre ellas sin evidencia.

**No usar Family A/B como criterio de evaluación del Plan.**  
Family A/B (u otros playbook labels) pertenecen a la **investigación posterior de la causa**, no al veredicto de fallar o no el Plan.

### 8. No explicar por obligación

Demostrar que el Plan estuvo equivocado **no requiere demostrar por qué**.

`Inconclusive` es un resultado legítimo.

No forzar:

- un playbook alternativo;
- una entry retrospectivamente perfecta;
- una explicación de velas;
- una característica “especial” del ticker;
- una Improvement Hypothesis sin evidencia.

## Qué preservar para la población

Un caso no necesita resolver el misterio. Preservar el error permite preguntar después:

- ¿Cuántos Plans quedan demasiado profundos?
- ¿Con qué playbooks?
- ¿En qué tickers?
- ¿Cuántos fueron tesis correcta + Plan fallido?
- ¿Cuántos no-fill estuvieron >2R, >3R, etc. de la estructura efectiva?
- ¿Cuántos posibles playbook mismatches aparecen?

Los datos pueden revelar lo que **hoy legítimamente no sabemos**.

## SHOP · PLAN-005 — reference example (anti-misinterpretation)

**Original Plan**

| Field | Value |
|---|---|
| Thesis | bullish |
| Decision | WAIT |
| Entry | 136 |
| Stop | 125 |
| Target | 180 |
| Entry→Stop distance | 11 |
| Planned R:R | 4R |
| Proposed area | approximately 133–138.75 |
| Execution | none |

**Original geometry expressed using the 11-point risk distance**

| Marker | Price |
|---|---|
| Entry | 136 |
| +1 distance | 147 |
| +2 | 158 |
| +3 | 169 |
| Target | 180 |

**Reality**

- The planned entry and proposed support area were not reached.
- The relevant market structure developed materially above the planned entry.
- The market subsequently reached and exceeded the original 180 target.

**Evaluation**

| Layer | Verdict |
|---|---|
| Thesis | broadly correct |
| Plan | **failed** |
| No-chase discipline | preserved — good discipline |
| Realized R | 0R |
| Counterfactual R | 0R (entry never activated; sealed R semantics unchanged) |
| Exact causal attribution | unresolved / inconclusive unless T0 evidence supports more |

**The important conclusion is NOT**

> "SHOP went up, therefore we should have chased it."

**It is**

> "The Plan's expected opportunity geometry was materially wrong. We correctly did not chase an unidentified structure. We know the Plan failed; we do not yet need to know exactly why."

### Forbidden reinterpretations (SHOP)

1. Do not retrospectively invent an ideal SHOP entry.
2. Do not declare that another Playbook was definitely identifiable at T0.
3. Do not convert later price movement into evidence that chasing was correct.
4. Do not treat target-reached as proof the Plan was good.
5. Do not treat historical technical defensibility of 136 as proof the Plan was approximately correct when Reality materially falsified the expected geometry.
6. Do not refuse to classify Plan failure merely because the cause is unknown.

**Preserve the error as data for later population-level learning.**
